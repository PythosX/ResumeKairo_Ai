# ResumeKairo — 20 Full A4 Templates with Photo Boxes

All 20 templates are full A4-sized HTML/CSS layouts and include a dedicated profile photo box.

Each template is standalone and can be rendered with browser print, Playwright/Chromium, or another HTML-to-PDF engine.

## Dynamic fields

The templates intentionally include attributes such as:

`data-field="name"`
`data-field="title"`
`data-field="email"`
`data-field="phone"`
`data-field="location"`
`data-field="linkedin"`
`data-field="summary"`

The photo placeholder uses:

`data-photo-box`

Your application should clone/load the selected template and inject the user's JSON resume data into the corresponding fields.
